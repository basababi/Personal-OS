# ⚡ Personal OS — Windows Desktop апп

Басбишийн хувийн үйлдлийн систем: MLOps инженер болох 9 сарын зам · English A1→B2 аялал · өдрийн төлөвлөгөө · хэвшлийн tracker · аналитик. Прототип дизайныг pixel-perfect буулгаж, жинхэнэ Windows desktop апп болгосон.

## 🚀 Эхлүүлэх

| Арга | Хэрхэн |
|---|---|
| **Desktop shortcut** | Desktop дээрх **Personal OS** icon дээр дар (аль хэдийн үүссэн) |
| **Start Menu** | Start → "Personal OS" гэж хай |
| **Гараар** | `Personal OS.vbs` файлыг давхар дар |
| **Терминалаас** | `npm start` (энэ хавтаст) |

Хаах товч дарахад апп **tray-д нуугдана** (баруун доод буланд цахилгааны icon) — сануулгууд ажилласаар байна. Бүрэн гарахыг хүсвэл tray icon → **Гарах**.

## ✨ Юу чадах вэ

### Прототипоос авсан 5 дэлгэц (бүгд ажиллагаатай)
1. **Хяналтын самбар** — амьд цаг, мэндчилгээ, өнөөдрийн фокус, хэвшлийн mini-grid, 14 хоногийн бодит судалгааны график, milestones
2. **Өдрийн төлөвлөгч** — цагийн блокууд («ОДОО» badge), даалгавар (area + priority), өглөөний routine, өнөөдрийн дүн
3. **MLOps төв** — 4 үе шаттай roadmap, статус эргэлдэнэ, төслүүд
4. **English OS** — A1→B2 stepper, Word Bank, дүрмийн tracker, минутын лог
5. **Зорилго & Хэвшил** — зорилгын картууд, 7 хоногийн habit grid, аналитик 3 график

### Desktop апп болгож нэмсэн чадварууд
- 🔔 **Windows-ийн жинхэнэ мэдэгдэл** — цагийн блок эхлэхэд сануулна (07:00 routine, 19:00 English, 20:00 MLOps, 21:30 review, 22:15 унтах, Ням гарагт 7 хоногийн review). Мэдэгдэл дээр дарахад холбогдох дэлгэц нээгдэнэ.
- 🧠 **Ухаалаг сануулга** — аль хэдийн хийчихсэн бол (ж: English 30+ мин суралцсан) сануулахгүй алгасна
- 🖥 **System tray** — хурдан навигаци, сануулга on/off, Windows-тэй асаах toggle
- ⚙️ **Тохиргоо дэлгэц** — сануулга нэмэх/засах (цаг, гараг сонгох), цагийн блок editor, routine алхам editor, нэр солих
- 🚀 **Windows-тэй хамт асаах** — асаавал компьютер асахад tray-д чимээгүй сууна
- 💾 **Бодит дата** — `%APPDATA%\PersonalOS\data.json` файлд хадгалагдана (өдөрт нэг удаа автомат backup хуулбар үүснэ). Тохиргооноос **Backup хадгалах / Сэргээх** хийж болно.
- 📊 **Бодит статистик** — English/MLOps-ийн өдөр тутмын минут жинхэнэ түүхэнд хуримтлагдаж график зурагдана (демо тоо байхгүй)
- 📅 **Өдрийн rollover** — шөнө 12 цагт routine/лог автоматаар шинэ өдөрт шилжинэ, долоо хоног солигдоход habit оноо түүхэнд орно
- ⏰ **Хоцорсон даалгавар** — өчигдрийн дуусаагүй даалгаврыг харуулж, нэг товчоор өнөөдөрт шилжүүлнэ
- 🌓 Light / Dark горим, фонтууд локалд — офлайн бүрэн ажиллана

## 🗂 Өгөгдөл хаана байдаг вэ

- Үндсэн файл: `C:\Users\Dell\AppData\Roaming\PersonalOS\data.json`
- Автомат backup: `data.backup.json` (өдөрт 1 удаа)
- Цонхны байрлал: `window-state.json`

## 🛠 Хөгжүүлэлт

```bash
npm install          # хамаарлууд
npm run build        # renderer-ийг dist/ рүү build хийнэ
npm start            # аппыг ажиллуулна (build хийсний дараа)
npm run dev          # Vite dev server (браузерт UI хөгжүүлэх)
npm run make:icons   # икон дахин үүсгэх
npm run fetch:fonts  # фонт дахин татах
npm run shot         # бүх дэлгэцийн скриншот (shots/ хавтаст)
```

Бүтэц: `electron/main.cjs` (цонх, tray, сануулгын хуваарьлагч, IPC) · `electron/preload.cjs` (аюулгүй гүүр) · `src/` (React UI — theme токен, store, 6 дэлгэц) · `src/data/defaults.ts` (эхлэлийн бодит дата, миграци).

> UI код солиход: `npm run build` дараа нь аппыг дахин нээ.
